배포 안내 (교사 공유용)
========================

■ 폴더 통째로 복사해서 나눠 주세요.
  name-quiz 폴더를 USB/클라우드로 전달하면 됩니다.

■ 받는 선생님 PC에 필요한 것
  1) Python 3  https://www.python.org/downloads/
     ※ 설치할 때 "Add python.exe to PATH" 꼭 체크
  2) Chrome 또는 Edge 브라우저

■ 실행 방법 (주소 입력 없음!)
  가장 쉬운 방법:
    1) make-desktop-shortcut.bat 을 한 번 더블클릭
    2) 바탕화면에 생긴 "NameQuiz" 아이콘을 더블클릭
    3) 브라우저가 자동으로 열려요

  다른 방법:
    - start.vbs 더블클릭 (검은 창 거의 없음, 추천)
    - start.bat 더블클릭 (상태를 보고 싶을 때)
    - "이름외우기 시작.bat" / "이름외우기 시작.vbs" 도 동일

■ 사용 흐름
  1) 실행 → 브라우저 자동 실행
  2) "엑셀 불러오기"로 사진 명렬표(.xlsx) 가져오기
  3) 퀴즈로 이름 외우기

■ 참고
  - 학급 데이터는 그 컴퓨터의 브라우저에만 저장됩니다.
  - 항상 같은 주소(http://127.0.0.1:5500)로 열어야 데이터가 유지됩니다.
  - NameQuiz / start.vbs / start.bat 로 실행하면 주소가 고정됩니다.
  - Chrome 설정에서 "브라우저를 닫을 때 데이터 삭제"가 켜져 있으면 저장이 지워집니다.
  - 시크릿(방비밀) 창에서는 저장되지 않습니다.
