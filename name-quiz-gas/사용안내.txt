네임퀴즈 Apps Script — 빠른 설치
================================

1. script.google.com → 새 프로젝트
2. Code.gs / Index / Styles / Client 파일 붙여넣기
   (HTML 파일 이름은 Index, Styles, Client — 확장자 없이)
3. setupNameQuiz 실행 → 권한 허용
4. 배포 → 새 배포 → 웹앱
   - 실행: 나
   - 액세스: 나
5. 나온 URL을 폰/PC에서 열기

데스크톱 백업 가져오기
----------------------
1. 네임브릿지_백업_….zip 을 Google Drive에 업로드
2. 웹앱 → 「백업 가져오기」
3. 파일 선택 또는 Drive 파일 ID 입력
4. 덮어쓰기 / 합치기 선택 후 가져오기
   (학급 14개·사진 많으면 수 분 소요)

---------
Drive 「네임퀴즈 / 학급이름」 폴더에
  01_홍길동.jpg  형식으로 올린 뒤
