# 네임퀴즈 (Google Apps Script 웹앱)

개인용 스마트폰/PC에서 쓰는 이름 암기 퀴즈입니다.  
**Google 시트**에 학급·학습 기록, **Drive**에 학생 사진을 둡니다.

## 한 번에 하는 설치

### 1) Apps Script 프로젝트 만들기
1. [script.google.com](https://script.google.com) 접속
2. **새 프로젝트** 생성
3. 기본 `코드.gs` 내용을 지우고, 이 폴더의 `Code.gs` 전체를 붙여넣기
4. 왼쪽 **+** → **HTML** 로 아래 파일을 각각 추가하고 내용 붙여넣기  
   - `Index` ← `Index.html`  
   - `Styles` ← `Styles.html`  
   - `Client` ← `Client.html`  
   ※ 파일 이름에 `.html`을 붙이지 마세요. Apps Script에서는 `Index`, `Styles`, `Client` 입니다.

### 2) 초기 설정 실행
1. 편집기 상단 함수 선택: `setupNameQuiz`
2. **실행** 클릭 → 권한 허용 (본인 Google 계정)
3. 실행 로그/반환값에 스프레드시트·폴더 URL이 나옵니다  
   - Drive에 `네임퀴즈` 폴더  
   - 그 안에 `네임퀴즈 데이터` 스프레드시트

### 3) 웹앱 배포
1. **배포** → **새 배포**
2. 유형: **웹앱**
3. 설정  
   - 실행 계정: **나**  
   - 액세스 권한: **나** (나만 사용)
4. 배포 후 나온 **웹앱 URL**을 북마크하거나 폰 홈 화면에 추가

코드를 수정한 뒤에는 **배포 → 배포 관리 → 연필(수정) → 새 버전**으로 다시 배포해야 반영됩니다.

## 데스크톱 백업 가져오기
데스크톱 `네임브릿지_백업_YYYYMMDD.zip` 을 웹앱으로 옮길 수 있습니다.

1. zip 파일을 **Google Drive**에 업로드 (내 드라이브 또는 `네임퀴즈` 폴더)
2. 웹앱에서 **백업 가져오기**
3. 목록에서 고르거나, 파일 링크의 ID 입력  
   - 링크 예: `https://drive.google.com/file/d/파일ID/view`
4. **덮어쓰기** 또는 **합치기** 선택 후 가져오기  
   - 학급·사진이 많으면 몇 분 걸릴 수 있고, 중간에 “이어서”가 자동으로 이어집니다.

학습 기록(정답/오답/복습)도 함께 옮겨집니다.

## 사용 방법

1. 웹앱에서 **학급 만들기**
2. 사진 넣는 방법 (둘 중 하나)
   - **A. Drive 동기화 (추천)**  
     Drive `네임퀴즈 / (학급이름)` 폴더에 사진을 넣고, 앱에서 **사진 동기화**  
     파일명 예:
     - `01_홍길동.jpg`
     - `1-홍길동.png`
     - `홍길동.jpg` (번호 없이 이름만)
   - **B. 앱에서 직접 업로드**  
     명단 탭 → 학생 추가 → 사진 버튼
3. 퀴즈 모드 선택 후 연습

## 퀴즈 모드
- 사진 보고 이름 고르기
- 이름 보고 사진 고르기
- 연습하기 (카드 뒤집기)
- 이름 직접 입력
- 약한 학생만 / 복습 대기

학습 기록(정답·오답·복습 간격)은 시트 `Students`에 저장됩니다.

## 데이터 위치
| 구분 | 위치 |
|------|------|
| 학급·학생·점수 | 스프레드시트 `Classes`, `Students` |
| 사진 파일 | Drive `네임퀴즈/(학급명)/` |

## 참고
- 웹앱은 Google 로그인(본인 계정)이 필요합니다.
- 사진이 매우 크면 업로드 시 자동으로 줄입니다. Drive에 직접 넣을 때도 너무 큰 원본보다는 적당 크기가 빠릅니다.
- 엑셀 명렬표 자동 가져오기는 아직 없습니다. Drive 파일명 동기화 또는 수동 추가를 사용하세요.

## 이 폴더 파일
